Algorithms as generators

Each algorithm is a JavaScript function* that yields one event per comparison, swap or visited cell. The renderer never touches algorithm code, so pausing, stepping and speed control come for free.

Counted, not guessed

Comparisons and writes are tallied from the yielded events, and every finished sort is checked against a sortedness test before the bars turn green.

No dependencies

Plain HTML, CSS and Canvas 2D. A binary heap drives Dijkstra and A*, and a Compare button runs all five searches on your board and times them.
